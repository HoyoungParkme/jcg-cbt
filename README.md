# 정처기 기출 데스크

정보처리기사 필기(2020-1·2 ~ 2026-1, 19회차 1,900문항) · 실기(2020-1 ~ 2026-2, 21회차 420문항) 복원 기출을 푸는 정적 CBT.
서버 없이 동작하고, 학습 기록은 브라우저 localStorage 에만 저장된다.

## 실행
- `index.html` 을 브라우저로 바로 열거나 (file://),
- `python3 -m http.server 8000` 같은 정적 서버로 서빙한다.
- 코드 하이라이팅(highlight.js)과 글꼴은 CDN에서 받으므로 오프라인이면 평문으로 보인다.

## 구조
```
index.html            화면·로직 전부 (CSS/JS 인라인)
data/manifest.js      회차 목록(응시자 평균 점수), 단원 목록, 단원×회차 문항 수
data/notes.js         과목별 요약노트 (필기 5과목 + 실기)
data/written/*.js     필기 회차별 문제  window.CBT_DATA["written/2024-1"]
data/practical/*.js   실기 회차별 문제  window.CBT_DATA["practical/2024-1"]
data/img/             문제에 딸린 그림·표 이미지 (188장)
data/trace/           실기 코드 문항의 실행 추적 (135개, 문항을 열 때만 불러옴)
```
회차 파일은 필요할 때 `<script>` 태그로 읽어오므로 처음 로딩이 가볍다.

## 기능
- 학습 방식: 회차별 / 단원별(단원·회차 다중 선택, 문항 수·순서·보기 섞기) × 시험 / 해설 / 오픈북 모드
- 해설 모드: 고르면 바로 채점, 해설(정리/등록자/AI)·IT위키 링크, 다시 풀기, 보기 소거
- 시험 모드: 150분 타이머, 제출 후 채점. 필기는 과목당 40점 미만 과락·평균 60점 합격, 실기는 60점 합격 (회차별 전용)
- 오픈북 모드: 정답·해설을 펼쳐 두고 회독
- 복사 / AI에게 묻기: 문제를 텍스트로 복사하거나 상세 해설 요청 프롬프트와 함께 복사
- 실행 추적 (실기 C·Java·Python 135문항): 코드를 실제로 실행(gdb·JDI·sys.settrace)해 한 줄씩 따라가며 **흥달쌤 손풀이 양식**의 판을 그린다.
  - 변수는 `주소 이름 값` 한 줄. 값이 바뀌면 옛 값에 빗금을 긋고 옆에 새 값(노란 칸 = 이번 단계에 적힌 값). 아직 값이 없는 C 변수는 `?`
  - 주소는 변수마다 100, 200, 300…, 배열 원소는 100, 101, 102… (2차원은 행 주소가 원소 수만큼 뜀). 배열·포인터가 가리키는 변수·이름이 겹치는 변수에만 적고, "주소 모두 보기"로 전부 켤 수 있다
  - 배열은 가로 칸(옛 값은 위에 작게), 구조체 배열은 필드 열 × 인덱스 행, 객체(Java·Python)는 `번호 클래스 필드 값` 한 줄, 포인터 값은 가리키는 주소 번호 + `→ 어느 변수`
  - 함수를 부르면 그 함수의 변수 묶음(`swap(11, 19)`)이 새로 생기고 돌아오면 지워진다(static 변수는 위에 남음). 돌려준 값은 부른 코드 줄 옆에 `func(1) = 1`
  - 재귀는 아래→위로 쌓이는 표(매개변수 + R 열 = 돌려줄 식, `3 * func(2)` → 돌아오면 `3 * 2 = 6`)
  - 출력은 실제 모양 그대로 누적 (줄바꿈 ↵, 공백은 밑줄), 코드 줄 끝 ✓ 는 실행된 줄. `[` `]` 키로 이동
  - 지금 줄에 덧쓰는 값(2차 분석 반영): 조건식은 값을 넣은 비교식과 결과 `a[j] > a[j+1] → 95 > 100 → 0` (C 1/0, Java true/false, Python True/False), 배열 인덱스 `a[j+1] → a[3] = 100`, 포인터 역참조 사슬 `**pp = *(200) → *(100) → a (10)`, `(p+1)->hab → 101 → st[1].hab`
  - 두 갈래 재귀(피보나치형)는 위→아래로 펼치고, 단일 재귀는 아래→위로 쌓는다. 주소는 포인터·배열·같은 이름 변수가 나오는 문제에서만 모든 변수에 붙인다. 초기화 없는 배열은 값이 들어온 원소만 보이고 나머지는 `?`
  - 실행되지 않은 문장은 빗금 + ✗ (거짓 if 의 몸체, 안 맞는 case, break·continue 로 건너뛴 줄, 참이 된 뒤의 else if). `&&`·`||` 단락 평가로 평가하지 않은 뒤쪽 식도 ✗ 로 표시. `(*p).필드` 도 `*(100).age → st.age` 로 풀어 쓴다
  - 객체 번호(100, 200)는 참조 공유(같은 객체를 두 변수가 가리킴)가 있는 문제에서만 붙이고, 없으면 `p1 · n Lee · a 45` 처럼 변수 줄에 객체를 바로 펼친다 (흥달쌤 규칙 8)
  - Python 리스트의 append·insert·pop 은 옛 줄을 빗금 치고 새 줄에 전체를 다시 쓴다. Java 부모·자식에 같은 이름 필드가 있으면 `A.x / B.x` 로 구분. 함수 기본값 리스트(`def f(x, y=[])`)는 호출이 끝나도 객체 칸에 남는다
- 계산 문제 풀이 판 (흥달쌤 방식, 정답·해설이 열릴 때 표시): 페이지 교체(FIFO·LRU·LFU·OPT, 참조열 위 + 프레임 줄 + 부재 O/X 줄), 프로세스 스케줄링(FCFS·SJF·SRT·RR·HRN·우선순위, 순서열 + 실행 길이, RR 대기 큐, 대기·반환 표, 장제법 평균), 디스크 스케줄링(FCFS·SSTF·SCAN·C-SCAN·LOOK·C-LOOK, 이동 거리 합), 서브넷(자릿값 줄 + 마스크·IP 비트, 범위표 `00: 0~63 …`, 네트워크·브로드캐스트·호스트 수, FLSM 분할), chmod·umask(4 2 1 표), LOC(장제법). 참조·시간·구간 하나마다 왜 그걸 골랐는지 번호 매긴 풀이 과정을 전부 적는다(긴 것이 정상). 문제 글에서 숫자를 읽어 채우고, 표가 그림으로만 있는 문제는 직접 입력한다. 값을 고치면 바로 다시 푼다
- 펜 모드 (아이패드 + 애플펜슬): 풀이 화면의 `✎ 펜` 을 켜면 문제 카드 위에 필기 레이어가 생긴다. 펜슬은 쓰고, 손가락은 스크롤·탭(버튼 누르기)으로 쓴다. 펜·형광펜·지우개(획 단위), 4가지 색, 굵기 3단계, 되돌리기, 여백 추가, 해설 패널 숨기기(넓게). 코드는 카드 왼쪽 60% 안에 두어 흥달쌤처럼 코드 오른쪽에 쓸 자리를 남긴다. 필기는 문항별로 브라우저(localStorage)에 저장되고 펜을 꺼도 그대로 보인다
- 실기 단답형 자동 채점(대소문자·공백·한영 표기 허용), 다중 빈칸, 서술형 자가 채점
- 과목별 연습(틀린 문제·안 푼 문제 우선), 랜덤, 오답노트, 북마크, 이어서 풀기
- 단축키: 1–4 선택, Enter 채점/다음, ←/→ 이동, B 북마크, Esc 답안판 닫기

## 출처
- 문제·보기·정답·단원·이미지: 꿈라CBT(quiz.dreaming-ryan.com)의 공개 API 데이터 (응시자 복원 기출). 해설은 가져오지 않았다.
- 해설(정리/등록자/AI)·정답률·단답 자동채점 규칙·요약노트: hj0304/cert 저장소 (원출처 newbt.kr). 문항 본문·정답 유사도로 사이트 문항에 매칭했다 (필기 799/800, 실기 357/420).
- 실행 추적: `scratchpad/trace/` 의 prep.py(빈칸 채우기·조각 코드 감싸기·입력값) → run_all.py(실행·정답 대조) → trace_all.py(gdb_trace.py / JdiTrace.java / trace_py.py → post.py 주소 단순화·미초기화 판정 → compress.py)로 생성. 반환값은 gdb FinishBreakpoint / JDI MethodExitEvent / sys.settrace return 으로 잡는다. 손풀이 양식은 흥달쌤 강의 분석 메모(흥달쌤_풀이방식_분석.md, 1·2·3차 86개 영상 + 캡처 50장)를 따른다.
- 개인 학습 목적으로만 사용한다.

## 배포
서버가 필요 없는 정적 파일(index.html + data/, 약 11MB)이라 GitHub Pages·Cloudflare Pages·Netlify 같은 무료 정적 호스팅에 폴더째 올리면 된다. 유지 비용 0원. 학습 기록(풀이·북마크·필기·펜 모드 설정)은 브라우저 localStorage 에만 저장되므로 기기마다 따로 쌓이고, 브라우저 데이터를 지우면 사라진다.
화면: 1000px 이하(태블릿 세로·폰)는 한 열로 바뀌고 답안 현황은 아래에서 올라오는 시트, 640px 이하(폰)는 여백·글자 크기를 줄인다. 판·표·코드 상자는 제 안에서 가로 스크롤.
